# Phase-gate decisions (plan Section 23.2)

One row per decision the plan lists for resolution at its phase gate. "Current choice" is what the
code does today, read from `src/` and `tests/`. Nothing here is a measurement: where a decision
would need a benchmark, the row says "not measured on this host" (this host cannot run the
Linux-toolchain lanes; see `benchmarks/ABLATIONS.md`). Plan Section 23.2 closes with "do not block
the core release on optional decisions; keep unsupported options disabled and document the
boundary", which is why undecided options below stay off by default.

Status values:

- **decided**: the code implements one choice and tests pin it.
- **default kept pending evidence**: the plan's default direction is what runs; the evidence that
  could change it has not been produced.
- **awaiting human approval**: an optional route exists but stays disabled until a person signs the
  matching record in `benchmarks/APPROVALS.md` (A.11, A.12, A.13). Those three records are the only
  human approvals; they are all still unsigned there.
