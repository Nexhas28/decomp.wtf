Discontinued

This project is discontinued.

I've decided to stop working on decomp.wtf and archive it.

Over the last few days I noticed that a lot of the decompilation community, the people who made the tools and projects all of this is built on, is against AI decompiling like this. I didn't make decomp.wtf to do any harm, but I respect their opinion, and that's why I'm stopping it here.

The code stays up on GitHub as it is, under the MIT license. If you want to fork it and keep going with it, you can. I won't fix issues, review pull requests or make new releases anymore. If you already have it installed it keeps working, it just won't get any updates.

If you do use it or build on it, please only use it on games you own, don't share the game code it produces, and respect the rules of the projects you work with, because many of them don't want AI-made contributions.

Thanks to everyone who tried it, reported bugs and sent fixes.

For Mac

decomp.wtf for Mac

A fork carries decomp.wtf on as a native Mac app (macOS 14 or newer). It runs decomp.wtf in its own window and updates itself. It needs uv and a copy of the source, and Docker Desktop for the compilers that only exist for Linux.

Download the latest Mac release from GitHub, or build it from source with Xcode and XcodeGen:

$git clone https://github.com/Nexhas28/decomp.wtf && cd decomp.wtf/macos && xcodegen generate && xcodebuild -project DecompWTF.xcodeproj -scheme DecompWTF -configuration Release -derivedDataPath build/DerivedData SYMROOT="$PWD/build" build
Setup, first launch and updates: the README.
