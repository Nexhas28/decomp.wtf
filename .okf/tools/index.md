# Tools

Third-party decompilation and reverse-engineering tools downloaded into `local-tools/` and smoke-tested on this Mac.

- [armips](./armips.md) - MIPS and ARM assembler by Kingcom that turns .asm files into exact target bytes for N64 and PSX code. (pass)
- [asm-differ](./asm-differ.md) - Side-by-side assembly diff tool that highlights mismatching instructions between target and compiled code for byte-matching decompilation. (pass)
- [asm-processor](./asm-processor.md) - Rust tool that lets hand-written MIPS assembly live inside IDO-compiled C for byte-matching decompilation. (pass)
- [binwalk (v3)](./binwalk.md) - ReFirmLabs' Rust binwalk v3 scans binary dumps for embedded signatures and extracts compressed or packed data. (pass)
- [ccc (PS2 symbol dumper)](./ccc.md) - Parses STABS debugging symbols from PS2 .mdebug sections to list types, functions and globals. (pass)
- [crunch64](./crunch64.md) - Command-line compressor and decompressor for N64 asset formats Yay0, Yaz0, MIO0 and gzip. (pass)
- [decomp-permuter](./decomp-permuter.md) - Randomised source permuter that searches equivalent C rewrites until a compiled function matches the target assembly byte for byte. (pass)
- [ds-rom](./ds-rom.md) - Rust CLI (dsrom) that dumps, extracts and rebuilds Nintendo DS ROMs for decomp projects. (pass)
- [findcode](./findcode.md) - Heuristic scanner that reports where MIPS code regions sit inside an N64 ROM (currently fails to build on macOS arm64). (fail)
- [GBA Ghidra Loader](./gba-ghidra-loader.md) - Ghidra extension that loads Game Boy Advance ROMs with the correct memory map, IO labels and entry point. (pass)
- [gbadisasm](./gbadisasm.md) - Disassembler for Game Boy Advance ROMs that turns ARM and Thumb code into assembly guided by a config file. (pass)
- [gclib](./gclib.md) - Python library implementing GameCube file formats (Yaz0, RARC, GCM, DOL, REL, BTI, J3D and more). (pass)
- [gfxdis](./gfxdis.md) - Command-line N64 RSP display list disassembler that prints gbi.h macros for F3D, F3DEX, F3DEXB and F3DEX2 microcode. (pass)
- [Ghidra Delinker Extension](./ghidra-delinker.md) - Ghidra extension that exports parts of a program as relocatable object files with a reconstructed symbol and relocation table. (pass)
- [Ghidra Emotion Engine Reloaded](./ghidra-emotionengine.md) - Ghidra extension that adds PlayStation 2 Emotion Engine (MIPS-R5900) disassembly, decompilation and PS2-specific analyzers. (pass)
- [Ghidra GameCube/Wii Loader](./ghidra-gamecube-loader.md) - Ghidra extension that loads GameCube and Wii DOL, REL, RSO, apploader and RAM-dump files with the Gekko/Broadway PowerPC language. (pass)
- [N64LoaderWV (Ghidra N64 ROM loader)](./ghidra-n64-loader.md) - Ghidra loader extension that imports Nintendo 64 ROMs with the N64 memory map, hardware register labels and automatic byte-order fixing. (pass)
- [NTRGhidra (Nintendo DS loader for Ghidra)](./ghidra-nds-loader.md) - Ghidra loader and plugin that imports Nintendo DS and DSi ROMs with the correct ARM9/ARM7 memory map, IO labels, overlays and entry point. (pass)
- [Ghidra PSX Loader](./ghidra-psx-ldr.md) - Ghidra extension that loads PlayStation 1 PS-X EXE files with the PSX memory map, hardware registers, GP setup and PsyQ signatures. (pass)
- [GhidraBoy](./ghidraboy.md) - Open-source Ghidra extension adding Sharp SM83 (Game Boy) language support and a Game Boy ROM loader. (pass)
- [ghidriff](./ghidriff.md) - Command-line binary diffing engine built on Ghidra that reports added, deleted and modified functions between two builds with decompiled-code diffs. (pass)
- [ido-static-recomp (recomp)](./ido-static-recomp.md) - Static recompiler that turns IRIX MIPS executables (such as the IDO 5.3/7.1 compiler passes) into native C programs for macOS and Linux. (pass)
- [Keystone](./keystone.md) - Multi-architecture assembler library that turns assembly text into machine-code bytes for byte-matching checks. (pass)
- [mapfile-parser](./mapfile-parser.md) - Python and Rust library plus CLI from Decompollaborate that parses GNU ld and clang lld linker maps into sections and symbols for decompilation progress tracking. (pass)
- [mGBA](./mgba.md) - Open-source Game Boy Advance emulator with a CLI debugger, used to run and inspect small GBA ROMs for byte-matching checks. (pass)
- [mkpsxiso (dumpsxiso)](./mkpsxiso.md) - Builds PlayStation 1 BIN/CUE disc images from an XML project and extracts disc images back to files. (pass)
- [mwccgap](./mwccgap.md) - Global assembly processor for MWCC that compiles INCLUDE_ASM functions as nops and transplants the real assembled instructions into the object. (pass)
- [N64Recomp](./n64recomp.md) - Static recompiler from N64Recomp that converts N64 MIPS ELF code and RSP microcode into portable C, with CLIs N64Recomp and RSPRecomp. (pass)
- [n64sym](./n64sym.md) - N64 symbol identification tool by shygoo that names known library functions in RAM dumps and ROMs by matching signature bytes. (pass)
- [ndspy](./ndspy.md) - Python library for reading, editing and creating Nintendo DS ROMs, NitroFS, LZ10 compression, NARC archives and ARM code sections. (pass)
- [ndstool](./ndstool.md) - Nintendo DS ROM packer and unpacker from devkitPro that builds, inspects and extracts .nds ROMs. (pass)
- [nodtool](./nodtool.md) - Command-line tool that reads, extracts, converts (ISO and RVZ) and verifies GameCube and Wii disc images. (pass)
- [PCSX-Redux CLI tools (psyq-obj-parser, ps1-packer)](./pcsx-redux-tools.md) - Command-line PSY-Q object converter and PS-EXE packer from the PCSX-Redux PlayStation 1 emulator project. (pass)
- [pigment64](./pigment64.md) - Command-line and Rust library that converts N64 texture formats to and from PNG. (pass)
- [pret GBA tools](./pret-gba-tools.md) - Command-line converters from the pret GBA decompilation project (gbagfx, preproc, scaninc, gbafix and more) that rebuild GBA assets byte-for-byte. (pass)
- [pygfxd](./pygfxd.md) - Python ctypes bindings for libgfxd, which disassembles N64 F3D/F3DEX2 display lists into gsSP/gsDP C macros. (pass)
- [pypcode](./pypcode.md) - Python bindings to Ghidra's SLEIGH library that disassemble raw machine code and lift it to P-code for byte-level checks. (pass)
- [radare2](./radare2.md) - Open-source reverse engineering framework with disassemblers and assemblers for MIPS, Thumb, PowerPC and SM83, plus ESIL emulation and binary analysis. (pass)
- [RetDec](./retdec.md) - Open-source (MIT) machine-code decompiler from avast that produces C-like code from MIPS, PowerPC, ARM and other binaries. (pass)
- [rizin](./rizin.md) - Command-line reverse-engineering framework (radare2 fork) used to disassemble, assemble and emulate console CPU code for byte-matching work. (pass)
- [rz-ghidra](./rz-ghidra.md) - Rizin plugin that adds Ghidra's decompiler (pdg command) and SLEIGH disassembly to rizin for many CPU architectures. (pass)
- [slinky](./slinky.md) - Linker script generator from decompals that builds GNU ld and LLVM lld scripts for matching decompilation projects from a small YAML segment list. (pass)
- [Torch](./torch.md) - Generic N64 asset processor that extracts ROM assets into an OTR archive or C source. (pass)
- [Unicorn](./unicorn.md) - Multi-architecture CPU emulator framework (QEMU-based) with Python bindings, used to run small code or data routines and inspect their register and memory results. (pass)
